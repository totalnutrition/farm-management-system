# Project instructions

## Coding & design

Read [docs/guidelines.md](docs/guidelines.md) before adding any feature. It is the spec for stack, directory layout, auth, RLS, naming, forms, server actions, and commit conventions. Match what already exists.

## Pull requests

- Only create a PR when the user explicitly asks.
- After creating a PR, auto-merge it into `master` via `mcp__github__merge_pull_request`. Use the default merge method unless the user specifies otherwise.
- If the merge is blocked (failing checks, conflicts, branch protection, required reviews), do not retry or force it — surface the blocker to the user and wait for direction.
- Never force-push to `master`.
